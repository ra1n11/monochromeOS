# monochromeOS
A minimalist, customizable desktop experience built inside your browser. monochromeOS brings a monochrome interface, draggable windows, a taskbar, a Start menu, apps, and personalization features to your New Tab page.
# monochromeOS v1 Beta

**A desktop experience inside your browser.**

monochromeOS changes your browsers New Tab page into a desktop environment, including a Start menu, taskbar, movable windows, apps and options to personalize.

> **Status:** v1 Beta. Development. Bugs and incomplete features are expected.

## Features

- Minimalist monochrome desktop interface

- Custom Start menu with app search

- Taskbar with app buttons

- Draggable and resizable application windows

- Minimize, maximize, restore and close windows

- Built-in Browser app

- App Store with website shortcuts

- Custom wallpapers and accent colors

- Dark and light appearance options

- Adjustable window opacity and animations

- Live clock and date

- Custom favicon and Start button logo

Some websites may stop embedded viewing. Those websites can be opened in a browser tab instead.

## Installation

### Requirements

- A Chromium-based browser that supports Manifest V3 extensions

- The monochromeOS project files

### Steps

1. Download the project from this GitHub repository.

2. If downloaded as a ZIP extract it to a folder on your computer.

3. Open your browsers extensions page:

Browser link: `*browser name*://extensions`

4. Turn on **Developer mode**.

5. Select **Load unpacked**.

6. Choose the extracted `monochromeOS` project folder. The folder containing `manifest.json`.

7. Open a tab to start monochromeOS.

### Updating

1. Get the project files.

2. Replace the project files while keeping your custom assets if needed.

3. Go back, to the extensions page.

4. Click the reload button on monochromeOS.

5. Open a tab to test the update.

## Important Notes

- monochromeOS is a browser extension, not an operating system.

- The App Store adds website shortcuts, not desktop applications.

- Some websites cannot be embedded because of their security restrictions.

- This is a beta release so some features may not work exactly as intended.
